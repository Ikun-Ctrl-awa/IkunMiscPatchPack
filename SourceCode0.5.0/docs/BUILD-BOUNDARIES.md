# 构建边界

src中运行时代码与维护工程一致。公开工程仅将依赖和资源定位改为本地属性；原生测试及历史生成器的机器路径改为显式环境变量。真实账户、第三方反编译代码及测试宿主不分发。补齐私有输入后可重建模组；没有输入时应明确失败。

tools/Helpers保留此前自行编写的兼容辅助源码，按原命名空间组织在统一目录中；历史生成器涉及的二进制布局需由IKUN_PRIVATE_TOOL_INPUTS提供。当前版本化生成器使用私有输入根目录，私有目录包含catalog、assets、variants及api/release-blockers/original。

构建校验、原生完整回归及安装包字节一致性分别记录在交付校验文件中。没有实际执行的验证不能填写为通过。
