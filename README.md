# IkunMiscPatchPack
一个杀戮尖塔2模组
# 艾堃的杂项与补丁包

# 版本 0.1.0；适用于《杀戮尖塔 2》public-beta v0.111.0。

唯一模组前置：**RitsuLib 0.6.7 或更新的兼容版本**。不要求安装任何被修补的内容模组。原模组自身声明的前置仍由原模组负责。

## 配置

进入 RitsuLib 模组配置，选择“艾堃的杂项与补丁包”。

- **杂项**：更好的顶栏。顶部图标自动换行，使用原版石质背景扩展，适配遗物整理折叠按钮、遗物栏和右上角版本、种子等信息。
- **补丁**：17 个独立开关，每项附问题和修复说明。

首次加载默认全部开启。**修改选项后重启游戏生效**，同一次游戏中不会切换已经加载的程序集。

没有装载相关模组时，配置显示“未装载相关模组……补丁无效”，该项自动跳过。配置保留开启偏好，以后装载相关模组即可使用。不支持的目标 DLL 版本会显示“版本未适配”，不会强行覆盖新版本。

## 安装与旧版迁移

将发行目录 `AikunMiscPatchPack` 放入游戏 `mods`。在模组列表中将本包排在所有需要修补的模组之前；RitsuLib 会按依赖规则先加载。

本机可在退出游戏后运行 `Install-Local.ps1`：归档此前 13 个本地覆盖目录，安装本包并设置加载顺序。工坊原件不变，存档不变。不要同时保留此前的独立顶栏、融合任务补丁和各个 `_LocalFix` 修复目录，否则关闭开关后旧补丁仍可能生效。

本次旧补丁归档位置记录在 `verification/installation.txt`，归档目录也包含原设置与迁移路径清单。正常使用无需恢复这些旧目录。若需要回退，退出游戏后将本包移出 `mods`，再按迁移清单将旧目录移回；不要回滚之后游玩的存档。

RitsuLib 配置文件位于相应 Steam 账号目录的 `mod_data/AikunMiscPatchPack/options.json`，不增加当前局存档字段。

## 实现与验证

运行时读取目标原件并校验 SHA-256，再把选定修复组合写入独立缓存加载。不改写工坊 DLL、资源包或猪猪加载器的完整性清单。发行文件仅需本包 DLL 和模组清单，不附带原内容模组资源。
