# 0.5.0

版本 **0.5.0 测试开发版**；适用于《杀戮尖塔 2》public-beta v0.111.0（41cef1ea）。

## 0.5.0：艾堃的塔之诅咒扩展包

新增默认开启杂项 `tower_curse_expansion`。原独立“区”选项由此项替代；东尼的诅咒、东尼的厌恶也改由此项控制随机获取与生成。三张旧牌沿用原注册ID、卡图与结算规则，已有牌和存档不受开关影响。`dongni_content`继续管理五张非诅咒东尼牌、办公室事件和两件事件遗物。

- **卡了**：3费诅咒牌，保留、奇巧、消耗。被变化或消耗时，将1张本牌的复制品生成到手牌中。可以升级。
- **卡了+**：3费诅咒牌，保留、奇巧；升级移除消耗，变化和被其他效果消耗时仍生成复制品。

奇巧沿用原生弃牌时免费自动打出效果。复制品保留升级等级，属于本场战斗中的新牌，不添加永久牌组；满手时使用原生溢出至弃牌堆规则。按用户选择，仅战斗内变化生成复制品，战斗外变化不回填手牌或永久牌组，也不延后至下一场战斗。卡图使用黑紫暗色烟雾中的加载转圈原创图，普通版、升级版及测试图统一使用嵌入资源。含卡了的融合牌在战斗内被消耗或变化时，生成完整融合牌的复制品；保留父牌与所有素材的升级状态，不拆成单独的卡了。原生外层事件统一处理，每张实际离场的卡触发一次。区事件的固定诅咒代价继续独立于随机获取开关。

## 0.5.0：便携睡袋

新增默认开启杂项 `portable_sleeping_bag`。便携睡袋是商店遗物，使用原生商店稀有度和价格规则，初始1次可用次数，以遗物角标显示。战斗外右键点击，消耗1次进入额外休息房间，完成后返回原房间；支持事件、商店、原休息房间、宝箱及胜利奖励结算阶段。正在战斗或进行选牌等操作时不可进入。

普通休息处新增**整理**选项，每次补充1次可用次数，按原生规则占用一次休息选择。睡袋开启的额外休息处不能整理；次数可累积，无“一次整理回满”的设定。遗物关闭获取后，已有遗物仍可使用、整理和读档。

额外房间不重新生成地图，不增加路线楼层；暂存原房间节点、父火堆选择与同步状态、商店库存、事件实例和待领取奖励，返回时恢复原现场。原生休息治疗、锻造及其他休息选项沿用原生流程。额外房间存在期间不写不受支持的临时房间堆栈存档；退出游戏沿用已有正常检查点，正常返回后的次数可随原生存档保存。图标使用原创透明睡袋卷；遗物栏128像素、大图256像素，并有独立透明轮廓，整理按钮使用同一睡袋图标。

## 0.5.0：艾堃的X牌扩展

新增默认开启杂项 `x_card_expansion`，修改后重启生效。五张牌分别加入对应角色卡池，不加入无色卡池；关闭后停止获取，已持有的牌和存档仍可继续使用。

| 小刀雨 | 静默猎手 | X费稀有技能，生成并向随机目标打出2X张小刀 | 数量仍2X，生成并打出小刀+ |

| 舍身连击 | 铁甲战士 | X费稀有攻击，选至多X张非攻击牌消耗，获得等量临时力量，造成1点伤害X次 | 选牌上限与攻击次数均为X+1 |

小刀逐张生成并分别调用原生自动出牌，每张都从当时仍可攻击的敌人中独立随机选目标；目标死亡后后续小刀重新选取。生成的小刀沿用自身消耗、伤害、标签与原生触发。百冶使用原生铸造流程，包括X=0时原生铸造0的行为。玻璃厂先获得临时集中，再依次生成原生玻璃球；满槽时按原生规则激发，回合末只撤销本牌的临时集中。

舍身连击合并手牌、抽牌堆和弃牌堆中的非攻击牌供选择，可选0张，排除攻击牌、消耗堆和其他玩家的牌。临时力量在攻击前获得，回合末只撤销本牌增量；不论实际消耗几张，都按X（升级X+1）次攻击，本牌正常弃牌。

灵魂祭仪获得能量的卡面使用原生`energyIcons`格式，普通1个、升级2个能量图标，未改变效果。灵魂祭仪的能量只在打出时获得；每回合生成数量锁定为打出时的X，使用与原生无限刀刃相同的抽牌前回合开始钩子。普通和升级多次施放分别叠加，保留两种灵魂品质；手牌溢出沿用原生弃牌规则，未打出的虚无灵魂在回合末消耗。

所有X均使用打出时捕获的原生X值，兼容化学X和免费自动打出。补充东尼普通诅咒兑现作用域：已到期卡牌为同一玩家打出的子牌同时兑现，不再被重复延后；按玩家隔离并在结束后恢复原规则。五张牌分别使用原创小刀雨、星光锻造、玻璃球生产线、燃牌连斩及魂火仪式卡图，按对应角色原生卡牌风格绘制。普通、升级、测试图和预览共享各自图像，PNG嵌入DLL。原图、提示词和已核对牌池的参考目录见assets/card-art/x-expansion-0.5.0-v1/；被遗忘的仪式属于战士，未用于灵魂祭仪风格参考。

## 0.5.0：第四幕火堆闪退修复

新增默认开启补丁“Act 4 Heart：换幕火堆闪退”（`act4_audio_crash`），安装Act4Heart时应用，修改后重启生效。

已在隔离引擎重现与玩家一致的`0xc0000005 / coreclr.dll+0x2e9302`：往昔之章Boss胜利调用原生StopMusic，环境音事件已释放，但控制器仍缓存第三幕环境音路径。第四幕音乐bank加载失败转为OGG后，控制器因路径相同跳过恢复环境音；首个火堆更新Campfire参数时访问空事件导致进程终止。

补丁在停播后同步清除环境音缓存，并在第四幕火堆更新及熄灭前按需恢复实际事件。原生事件无法创建时略过该次失效营火参数调用，保留地图进度更新。继续使用第四幕原有OGG音乐、地图、战斗和钥匙流程，不需要迁移存档。

## 0.5.0：融合注能开局自动打出

修复注能保留在融合素材或复合/额外附魔槽中，整张融合牌却漏掉首回合自动打出的问题。沿用原 `plague_imbued_autoplay` 开关，名称改为“复合与融合：注能自动打出”；安装 Plague 或卡牌融合即可启用，49项主配置不变。首回合自动打出实际融合牌一次，保留原生选目标、免费出牌、素材效果和弃牌/消耗规则，支持战斗克隆与旧卡牌读档；不改写永久牌组的附魔。

## 0.5.0：mod形态衍生卡开关

“杂项 → mod形态 → 展开”新增“生成衍生卡”开关，默认开启，旧配置缺少此字段时同样开启以保持原规则。关闭后，衍生稀有度（Token）的卡牌不进入mod形态候选池；开启时仍须满足原有的可生成、可打出等条件。只影响mod形态生成，不改变其他卡牌的生成效果。“自身参与生成候选”仍独立控制，修改后重启生效。仍为49个主选项（9杂项、40补丁），本轮只增加mod形态的一个子设置。

## 0.5.0：东尼的厌恶

沿用`dongni_content`开关，加入诅咒卡池。普通/升级均为0费诅咒卡，虚无、消耗，可以打出；只允许升级一次，升级版打出额外抽1张牌。

真正加入永久牌组时，为当时牌组中的所有其他卡牌添加原生永恒，排除这张牌自身；不持续影响之后新获得的牌。升级、预览、战斗克隆和读档不重新触发添加。第二张厌恶加入时，会影响先前已在牌组中的第一张；只排除本次加入的实体。

从永久牌组成功变化或移除后，普通版通过原生同步选牌界面选择0～5张有永恒的牌（允许不选），移除所选牌的永恒；升级版直接移除牌组中所有卡牌的永恒，不打开选牌界面。不移除卡牌，不清除其他关键词或附魔。战斗中打出消耗、虚无消耗和战斗内变化不触发永久牌组清理。

已有永恒的卡牌不会再次调用添加永恒；原生关键词集合去重，同一卡牌即使有本体、附魔等多个永恒来源，也只保留一个有效永恒，解除时一并清除，并保留原附魔的其他效果和读档结果。已覆盖特兹塔卡拉的余烬、进阶之灾和禁忌魔典。

实际火堆融合及再次融合属于素材替换，不重复触发厌恶的离组/加入效果；完成后取消成品及素材的永恒。只要融合卡中仍含厌恶，它就不能获得永恒（包括之后新厌恶赋予、附魔、动态关键词、克隆和读档）。之后正常移除或变化成品时，按其中厌恶的原/升级版本正常结算，普通版选至多5张、升级版自动全解除；不影响其他玩家或不含厌恶的融合牌。

永恒的添加/解除结果使用Ritsu随卡能力保存和独立克隆，不占用原生附魔槽。仅操作持有者的永久牌组；兼容融合父卡/素材的加入与永久离开。与东尼的诅咒共同存在时，可打出的诅咒也会按其规则延后生效；永久加入、移除的效果不受出牌延后影响。

专属卡图由内置image_gen依据同一人物参考绘制：卷发胡须男子伸手指责，暗紫黑色调。最终PNG嵌入DLL，普通、升级、百科与预览使用同一可重新加载纹理路径，无额外PCK；原图和提示词保存在维护工程assets/card-art。

## 0.5.0：东尼的诅咒

沿用`dongni_content`杂项，不增加开关。加入诅咒卡池，可升级一次；普通版和升级版均3费、消耗，可以打出。打出本身无额外效果，用于消耗该牌并解除其在手牌中的限制。

- 普通版在自己的手牌中时，出牌仍在当时支付费用，原牌按原生规则进入弃牌堆、消耗堆或移除；卡牌效果及实际出牌结算延后到自己的下回合开始自动出牌阶段，按原打出顺序执行。费用不再支付，X费使用打出时保存的X值，原牌不从弃牌堆拿走，也不多留一份复制牌。已经排队的效果在诅咒被消耗或离手后仍会执行；多张诅咒不将同一张牌反复排队。
- 升级版只延后获得能量和效果抽牌，伤害、格挡等照常结算。使用原生下回合能量/抽牌状态；回合基础抽牌与到期兑现不再次推迟。海克斯“转起来”等提前兑现原生延后资源的效果优先，抽牌返回值也保留，避免影响后续处理所抽卡牌的效果。

只对持有者生效，退出战斗清除排队记录。关闭杂项只停止后续获取，已有牌的使用、升级和存档恢复继续保留。卡图依据用户提供的人物参考，由内置image_gen绘制为暗紫黑色调的蹲地画圈诅咒场景；最终PNG嵌入DLL并以可重新加载的纹理路径用于普通/升级卡面与预览，无额外PCK。参考原图和提示词只保留在维护工程，开发安装不复制参考原图。

## 0.5.0：！？区区？！

新增默认开启的独立杂项`qu_challenge_event`，仅在第一层问号房事件候选中允许抽到。事件名“！？区区？！”，描述“你惊扰了区！！！”。

- **迎战！**：先回复最大生命值的30%（按原生整数生命规则取整，最多至生命上限），固定进入原生异蛙寄生虫精英战斗。使用原有怪物、招式、召唤物及难度规则；胜利获得原生精英金币、1件遗物、1份卡牌奖励及原生概率药水，不额外重复发奖。其他模组与玩家遗物对精英奖励的正常修改继续生效。
- **搜、撤，不打。**：通过原生随机遗物工厂获得1件遗物，将1张未升级的“区”加入永久牌组，然后离开。此分支的明确诅咒代价不受`tower_curse_expansion`随机获取开关影响；原生防诅咒遗物等规则仍保留。

联机按原生战斗事件进行共同投票，每名玩家分别结算自己的回复或撤离奖励。事件使用原生战斗式画面展示异蛙寄生虫，无新增图片或模组前置。关闭此杂项只停止新事件抽取，仍登记模型以兼容已保存事件和战斗。

唯一模组前置：**RitsuLib 0.6.7 或更新的兼容版本**。不要求安装任何被修补的内容模组。原模组自身声明的前置仍由原模组负责。

“更好的顶栏”现会在大体型怪物的意图与顶栏重叠时，将整组意图图标及数值下移到顶栏下沿以下。按整段浮动动画的范围预留间距，保留原生动画、鼠标交互、水平位置和怪物本体站位。支持多意图、窗口缩放、多行和单行顶栏；顶栏隐藏、移出屏幕、体型标记重算或不再重叠时采用当前原生位置，不累加偏移。沿用`better_topbar`开关，不新增配置或改变战斗数据。

新增默认开启补丁“火堆融合：余烬默认费用”（`fusion_ember_cost`）。融合本体或任一子卡实际具有特兹塔卡拉的余烬时，将有限能量的默认费用统一为0；创建、进战斗克隆、读档和升级同步处理，支持更多附魔额外槽和Plague复合槽。保留正常的临时加减费及绝对费用修正、X费与星星规则，不需要修改玩家存档。

新增默认开启补丁“Plague：复合注能自动打出”（`plague_imbued_autoplay`）。Plague 1.0.0 的复合槽仍转发旧回合开始入口，漏掉当前游戏注能所用的首回合自动出牌阶段；神化的播种＋注能因此不触发。补丁仅为复合槽补发原生注能调用，保留正常神化升级、其他附魔、免费自动出牌和消耗规则。原生单槽注能不改写，已有卡牌存档无需迁移；Plague 未来已实现自动出牌阶段入口时不再补发。

吸血刀拾取时选永久牌组中的 0～3 张攻击牌，附魔泣血；每段卡牌直接造成的实际生命伤害按 25% 向下取整治疗，不计格挡吸收、过量伤害、能力或遗物追加伤害，不超过生命上限。与血魔宗原有吸血同时结算，泣血自身不产生临时血池。

雷电宗四选项为：获得雷电宗弟子令；永久牌组有电击、暴风雨、引雷针、球状闪电或电流相生时，获得暴风雨+与电流相生+；支付 150 金币获得电刀；离开。雷电宗弟子令保留原占位类型的注册位置和 ID，现已实现拾取时从永久牌组选择 0～3 张攻击或技能牌，附魔电弧。电弧每次打出对所有可受伤敌人造成 1 点伤害，不消耗附魔次数，不随力量增伤。

新增默认开启的杂项“东尼卡牌、遗物与事件”（`dongni_content`）。包含以下五张卡牌、东尼的办公室事件，以及东尼的祝福、东尼的思考两件事件遗物。三张主卡均为 0 费无色罕见技能，两张衍生牌均为 0 费，五张牌均消耗。

| 卡牌 | 普通效果 | 升级变化 |
|---|---|---|
| 东尼意思 | 向手牌添加一张东尼打击和一张东尼防御 | 添加升级版衍生牌 |
| 不东尼意思 | 从手牌选择并消耗两张牌，再向手牌添加一组未升级衍生牌 | 可从手牌、抽牌堆和弃牌堆选牌 |

谁东尼意思只有一张可选牌时，按战斗卡牌生成随机数变化为打击或防御；没有可选牌时不变化。不东尼意思不足两张时消耗实际可选牌，仍生成一组衍生牌。变化在原战斗牌堆和原位置进行，不改永久牌组。打击只统计自己的相应牌堆，出牌区不计入，卡面预览也排除即将打出的本牌；总伤害走原生攻击增减伤结算。防御的普通版在自己回合结束时解除限制，包含药水、遗物与状态提供的格挡；升级版不会解除先前已经存在的限制。

两张衍生牌不参与普通随机生成，三张主卡可正常从无色卡池获取。关闭开关只停止获取，既有卡牌和存档仍可使用。五张牌已采用用户参考角色绘制的专属插画：三种思考姿态、出拳攻击和防御格挡。普通版、升级版、克隆及读回共享各自卡图，PNG 随 DLL 嵌入，无需额外 PCK。原图与内置 image_gen 提示词集保存在 `assets/card-art/dongni-0.4.0-reference-v1/`。

东尼的思考：拾取时将东尼意思、不东尼意思、谁东尼意思各一张直接加入永久牌组；使用原生遗物与卡牌保存接口，恢复遗物不会再次执行拾取发牌。

办公室事件使用独立办公室插画，背景按 55% 不透明度显示，保留原生标题、描述与四选项的前景布局。原图与生成提示词保存在 `assets/event-art/`，两件遗物使用本包 SVG 图标。
