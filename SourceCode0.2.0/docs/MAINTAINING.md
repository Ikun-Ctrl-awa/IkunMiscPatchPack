# 维护说明

主入口为 `AikunMiscPatchPack/src/Entry.cs`，配置定义在 `Options.cs`，差分缓存加载在 `RuntimeLoader.cs`。缺少可选模组时安全跳过；原件哈希不一致时拒绝套用旧差分。不要修改工坊原件。

当前发布基线为 public-beta v0.111.0、.NET 9、RitsuLib 编译 SDK 0.6.7。原本机完整工程上轮引擎记录为 1217 项完整模组检查、173 项最小环境检查，点火专项 32 项；这些历史记录不是本源码包的新引擎验收，也不随包发布私人证据。本源码包整理后会另做编译和结构检查。未做真人联机，未穷举所有第三方卡牌。

主目录 C# 功能代码保持原样。公开副本调整编译引用为本地属性；测试输出目录改为 AIKUN_TEST_OUTPUT，七咒故障存档夹具改为可选 AIKUN_BOSS_HP_INCIDENT_SAVE；原始存档不随包提供。涉及输出模式、历史审计或重建目录时，以各脚本顶部变量为准。

保留 3 项杂项和 32 项补丁的全部实现。普通 Harmony 修复不必重新生成全部二进制组合；改动原件修补逻辑时，先检查实际 API、备份本地输入、逐组合回归，再验证真实出牌、保存、克隆和缺少可选模组的路径。

永久点火与战斗临时附魔需区分；mod形态只能生成攻击／技能／能力牌；融合等级是素材等级之和；Boss 扣血必须避免面板与基础生命倍率重复。不要自动补回玩家旧存档的生命或已经消失的附魔。

运行原生夹具时应在独立游戏副本和独立用户目录中禁用 Steam，并准备测试保存后端。源包没有提供私人账户克隆脚本，因此需自行搭建夹具宿主，不可把探针直接放进正式游戏后认为是安全测试。
